# Diary of a Rock n' Roll Doctor

This directory is the native Dr. OMEB blog. Substack is not the primary publishing platform.

## Publishing rules

- Public blog URL: `/blog/`
- Publication name: **Diary of a Rock n' Roll Doctor**
- Legacy series name: **Doctor's Notes**
- Keep articles public by default; no paywall.
- Every post should use a unique slug under `/blog/<slug>/`.
- Add Article/BlogPosting structured data, canonical URL, title, description, publication date, author, and social metadata to each post.
- Add each published article to `/blog/index.html`, `/blog/feed.xml`, and `/sitemap.xml`.
- Prefer local images under `/assets/images/` rather than third-party-hosted images.
- Preserve or redirect legacy Bandzoogle article URLs during migration wherever possible.

## Editorial lanes

1. Music & rock history
2. Marketing & creator business
3. From the road / career stories
4. Gear, performance and music-making
5. Dr. OMEB / Rock n' Roll Church updates when they have lasting editorial value

## Workflow

Draft and approve the article, create the native post page, update the blog index/RSS/sitemap, commit to `main`, and let Cloudflare Pages deploy automatically.
